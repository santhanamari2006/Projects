# Building a Real-Time Chat Application Using Django Channels

## Project Description

This project is a real-time chat application developed using Django and Django Channels. It allows users to exchange messages instantly using WebSockets.

## Technologies Used

- Python
- Django
- Django Channels
- WebSockets
- HTML, CSS, JavaScript
- SQLite

## Features

- Real-time messaging
- WebSocket communication
- Chat room functionality

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/santhanamari2006/Django_Projects.git
   ```
   
2. Run database migrations:

   ```bash
   python manage.py migrate
   ```

3. Start the development server:

   ```bash
   python manage.py runserver
   ```

4. Open `http://127.0.0.1:8000/` in your browser.
