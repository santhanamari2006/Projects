# Multi-Vendor Digital Marketplace

A Django-based marketplace where sellers can manage products and customers can purchase products using Stripe Checkout.

## Features
- Product listing and details
- User registration
- Create, edit, and delete products
- Seller dashboard
- Stripe payment integration
- Purchase history
- Sales analytics and reports

## Technologies Used
- Python
- Django
- HTML, CSS
- Stripe
- Django ORM

## How to Run

```bash
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

## Purpose
This project demonstrates Django web development, database operations, product management, payment integration, and sales reporting.
