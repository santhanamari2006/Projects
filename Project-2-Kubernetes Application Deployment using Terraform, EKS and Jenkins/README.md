# Kubernetes Application Deployment using Terraform, AWS EKS & Jenkins

## Project Overview
Automated the deployment of an Nginx web application on Amazon EKS using Terraform for infrastructure provisioning and Jenkins for CI/CD pipeline automation.

## Technologies Used
- AWS EC2, EKS, IAM
- Terraform
- Jenkins
- Docker
- Kubernetes
- Git & GitHub

## Workflow
1. Provision Jenkins server infrastructure using Terraform.
2. Configure Jenkins and connect the GitHub repository.
3. Automate EKS cluster creation through a Jenkins pipeline.
4. Deploy the Nginx application using Kubernetes Deployment and Service manifests.
5. Verify application deployment and service status.

## Key Learnings
- Infrastructure as Code with Terraform
- CI/CD automation using Jenkins
- Kubernetes application deployment on AWS EKS
- Cloud resource management and cleanup
